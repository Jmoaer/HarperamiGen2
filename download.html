How to install

  1. Tap the download button above and wait for the file to finish downloading.
  2. Open it from your notifications or your phone's Downloads / Files app.
  3. Android will ask to allow installs from this app — tap Settings, turn on Allow from this source, then go back.
  4. Tap Install, then Open. The Harperami Gen 2 icon appears on your home screen.

You keep the same account: sign in with your choir username and password. Your songs, chat and private messages are the same as on the website.

If Android shows “App not installed”, it is usually an older copy signed with a different key — uninstall the old Harperami app first, then install this one.

Rather not install anything?

You can add the website to your home screen instead — open the choir app, then use your browser menu → Add to Home screen. It runs the same system.
